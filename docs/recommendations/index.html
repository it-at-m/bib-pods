Strategie Profil-Properties Verknüpfung on by default Solr-Query

Die Solr-Query wird aus dem Profil gebaut, das gerade im Browser gespeichert ist (Anmeldung „Lokal im Browser" bzw. „Nur in dieser Sitzung" auf der Plugin-Seite; ein Profil im Solid Pod kann diese Seite nicht lesen). Klick auf eine Query öffnet sie auf der Query-Seite.
